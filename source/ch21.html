第21章　推导与解析（一）：朗道理论、临界指数与标度关系

本章小结
  • 因为它把自由能写成序参量的多项式，于是临界指数由展开的阶数决定。
  • 它的适用范围由维度决定：上临界维度以上，平均场严格。
  • 这一章的意义是给出"形式化能走多远"的具体刻度。

本章主提问：朗道理论为什么能给出那么多"可算"的结论？

前面讲“序参量”“临界指数”，但没推导。这一章补上：从自由能出发，推出临界指数与标度关系。

21.1　朗道自由能

设序参量为 η，外场为 h。把自由能按 η 展开（对称性要求只含偶次项）：

`` F(η) = F₀ + a η² + b η⁴ − h η ``

其中 a = a₀(T − T_c)，b > 0。

为什么只含偶次项？ 因为 η → −η 是对称的（例如磁化方向翻转，能量不变）。这一条对称性，决定了临界指数的“普适”。

21.2　平衡态：对 η 求极小

`` ∂F/∂η = 2aη + 4bη³ − h = 0 ``

情形一：h=0。

  • T > T_c（a>0）：唯一极小在 η=0；
  • T < T_c（a<0）：η=0 变成极大，极小在 η² = −a/(2b)。

于是：

`` η = ± sqrt( a₀(T_c − T) / (2b) ) ∝ (T_c − T)^{1/2} ``

所以 β = 1/2。 这是平均场的第一条指数。

21.3　磁化率：对 h 求导

在 T > T_c、h→0 时，η ≈ h/(2a)，于是：

`` χ = ∂η/∂h = 1/(2a) ∝ (T − T_c)^{−1} ``

所以 γ = 1。

21.4　比热：对温度求二阶导

F 在 T_c 处有一个“折点”，比热 C = −T ∂²F/∂T² 出现有限跳变，而不是发散。

所以 α = 0（平均场）。

21.5　关联长度

在平均场里，关联函数 G(r) ∝ e^{−r/ξ}/r，而 ξ ∝ |T − T_c|^{−1/2}。

所以 ν = 1/2。

21.6　标度关系：指数之间不是独立的

临界指数不是“六个独立的数”，它们满足标度关系：

`` Rushbrooke: α + 2β + γ = 2 Widom: γ = β(δ − 1) Josephson: ν d = 2 − α Fisher: γ = ν(2 − η) ``

这些关系，把六个指数压缩成两个独立指数。 这就是“普适类”的数学基础。

21.8　这对本书的意义

本书的“普适类”不是空话：它有一套可推导的指数与标度关系。 但本书也承认：社会/历史系统，几乎不可能测出这些指数。 所以，本书只借“结构”，不借“数值”。

21.9　朗道理论的局限

朗道理论是“平均场”：它假设 η 在空间均匀。这忽略了涨落。

什么时候涨落可以忽略？ 当维度 d 大于“上临界维度” d_c 时。对标准相变，d_c=4。

为什么？ 用“金兹堡判据”：涨落在关联体积 ξ^d 内的方差，要小于 η 的均值。当 d>4，这个条件满足；当 d<4，涨落改写指数。

所以，朗道的指数（β=1/2 等）只在 d≥4 严格。 二维、三维的伊辛，指数不同——这就是“平均场失效”。

21.10　一阶相变的朗道描述

如果 b<0，自由能 F = aη² + bη⁴ + cη⁶（c>0），会出现“双阱”。

当 a 从正变负，两个极小“交换高度”——在某个 a_c，η=0 与 η≠0 的极小等高。这就是一阶相变：序参量跳变。

一阶相变的标志： 潜热、滞后、两相共存。

21.11　三临界点

如果 b 也随参数变化，在 b=0 处，系统从“二阶”变成“一阶”——这个点叫“三临界点”（tricritical point）。

它的意义： 它说明“相变的类型”本身，也可以随参数改变。“二阶”不是绝对的，它可以是“一阶”的边界。

21.12　朗道与本书

本书借“序参量”“对称破缺”“临界指数”，但不借“平均场”的强假设。原因：社会/历史系统，既没有“空间均匀性”，也没有“可测的涨落”。

所以，本书只借“骨架”，不借“血肉”。 这是“借用工具，不冒充理论”的又一处。

一句话带走：模型里的临界是干净的，真实系统里的临界是有噪声的。
