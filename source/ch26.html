第二十六章　推导与解析（二）：伊辛模型与重整化群

一盘围棋，越下越整齐：先是零散几子，后来连成片，最后整盘只剩两种颜色。秩序不是被摆出来的，是下出来的。

朗道理论是“平均场”。这一章讲“超越平均场”的两件工具：伊辛模型的精确解，与重整化群的“粗粒化”。

26.1　伊辛模型

`` H = −J Σ_{⟨ij⟩} s_i s_j − h Σ_i s_i, s_i = ±1 ``

为什么它重要？ 它是最简单的“有相变”的模型；它的临界指数，成了“普适类”的基准。

26.2　一维：没有有限温相变

用转移矩阵：

`` T = [ e^{K+h} e^{−K} ] [ e^{−K} e^{K−h} ], K = J/(k_B T) ``

配分函数 Z = λ_+^N + λ_−^N，λ_± = e^K cosh h ± sqrt(e^{2K} sinh²h + e^{−2K})。

关键： 对 h=0，λ_+ = 2 cosh K，λ_− = 2 sinh K，都是 T 的光滑函数。没有奇点，就没有相变。 所以一维伊辛在 T>0 时没有有限温相变。

这个结果很重要： 它说明“有相互作用”不等于“有相变”；维度是关键。

26.3　二维：Onsager 的精确解

`` sinh(2J/(k_B T_c)) = 1 ⇒ T_c = 2J / (k_B ln(1+√2)) ≈ 2.269 J/k_B ``

序参量在 T_c 附近：

`` η ∝ (T_c − T)^{1/8} ``

所以二维伊辛的 β = 1/8，与平均场的 1/2 不同。 这就是“平均场失效”的直接证据。

26.4　重整化群：把“粗粒化”写成变换

思想。 把自旋按块（如 2×2）聚合成“块自旋”，再问“块自旋之间的有效耦合 K' 是多少”。

一维的例子。 对一维伊辛，消去一半自旋，得到：

`` K' = (1/2) ln cosh(2K) ``

固定点： 解 K* = (1/2) ln cosh(2K*)，只有 K*=0 与 K*=∞——没有有限温固定点，与“一维无相变”一致。

二维的例子。 块变换有“有限温固定点” K*，在它附近线性化：

`` K' − K* ≈ λ (K − K*) ``

临界指数由 λ 给出：ν = ln b / ln λ（b 是块的大小）。

这就是“普适类”的来源： 不同的微观模型，只要“块变换”在同一个固定点附近有相同的 λ，就有相同的临界指数。

26.5　上临界维度

平均场在 d ≥ 4 时严格。为什么是 4？ 因为 d=4 时，涨落的“相空间”刚好让平均场自洽；d<4 时，涨落会“改写”指数。

这就是“上临界维度” d_c=4 的来历。

26.6　这对本书的意义

本书借用“普适类”的概念，但不借用它的数值。原因很简单：社会/历史系统，既没有“自旋”，也没有“块变换”，更没有“可测的临界指数”。

所以，本书只借“结构”（有固定点、有普适类），不借“公式”（具体指数）。 这是“借用工具，不冒充理论”的又一处。

26.7　一维转移矩阵的完整推导

设 H = −J Σ s_i s_{i+1}，配分函数：

`` Z = Σ_{s_1...s_N} Π_i T(s_i, s_{i+1}) ``

其中 T(a,b) = exp(K ab)，K=J/(k_B T)。矩阵形式：

`` T = [ e^K e^{−K} ] [ e^{−K} e^K ] ``

对角化： 特征值 λ_+ = 2 cosh K、λ_− = 2 sinh K。于是 Z = λ_+^N + λ_−^N。

关键： 当 N→∞，Z ≈ λ_+^N。λ_+ 是 K 的光滑函数，没有奇点——所以没有相变。

这个推导干净地说明： “有相互作用”不等于“有相变”；维度才是关键。

26.8　二维 Onsager：结果与意义

Onsager 在 1944 年给出二维伊辛的精确解：

`` sinh(2K_c) = 1 ⇒ K_c = (1/2) ln(1+√2) ≈ 0.4407 T_c = 2J / (k_B ln(1+√2)) ≈ 2.269 J/k_B ``

序参量 η ∝ (T_c−T)^{1/8}，比热对数发散，关联长度指数 ν=1。

意义： 它证明“相变可以在二维发生”，并且“平均场的指数是错的”。这是“普适类”概念的起点。

26.9　块自旋的详细计算

一维。 把两个自旋 s1,s2 合成块自旋 S（取多数）。消去 s 后，有效耦合：

`` K' = (1/2) ln cosh(2K) ``

固定点： K* = (1/2) ln cosh(2K*)。解只有 K*=0（高温）与 K*=∞（零温）——没有有限温固定点。

二维。 块变换更复杂，但存在“有限温固定点” K*。线性化 K'−K* ≈ λ(K−K*)，ν = ln b/ln λ。

这就是“普适类”的来源： 不同微观模型，只要“块变换”在同一固定点附近有相同 λ，就有相同指数。

26.10　普适类的实验验证

液-气与铁磁的临界指数，在实验中高度一致——尽管微观机制完全不同。

这是“普适类”最有力的证据： 它说明“临界行为”不依赖微观细节，只依赖“维度”与“对称性”。

但本书也承认： 社会/历史系统，几乎没有“可测的临界指数”。所以，本书只借“普适类”的概念，不借它的数值。

【人的尺度】一位化学系学生说，他第一次看到“临界指数与微观细节无关”时，觉得世界是可以被理解的。重整化群最动人的地方，不是技术，是它告诉人：在足够大的尺度上，很多差别会消失。
