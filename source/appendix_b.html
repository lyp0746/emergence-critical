B.1.6　代码骨架（便于复现，省略了参数解析与画图）

E1：棋盘式 Metropolis 的一次 sweep。

``python def sweep(s, T, rng): L = s.shape[0]; idx = np.arange(L) for color in (0, 1): # 棋盘式：同色格点互不影响 mask = ((idx[:, None] + idx[None, :]) % 2) == color nb = (np.roll(s, 1, 0) + np.roll(s, -1, 0) + np.roll(s, 1, 1) + np.roll(s, -1, 1)) dE = 2.0 * s * nb acc = (dE <= 0) | (rng.random(s.shape) < np.exp(-np.maximum(dE, 0) / T)) s[mask & acc] *= -1 ``

E2：集合式（ensemble）分支过程——为什么它快。

``python size = np.zeros(n); frontier = np.ones(n); active = frontier > 0 while active.any(): # 一次推进全部雪崩 size[active] += frontier[active] frontier[active] = rng.poisson(m * frontier[active]) frontier[size >= cutoff] = 0 active = frontier > 0 ``

关键点： 逐个体循环的复杂度是 O(总后代数)（可达 10⁶/次），集合式的复杂度是 O(最大代数)（约 10²），两者相差四到五个数量级。这是“把算法想清楚”比“换更快的机器”更有效的例子。

E3：对数分箱的正确拟合（这里最容易错）。

``python edges = np.geomspace(lo, hi, bins) h, _ = np.histogram(x, bins=edges) dens = h / np.diff(edges) # 必须除以箱宽 centers = np.sqrt(edges[:-1] * edges[1:]) alpha = -np.polyfit(np.log(centers), np.log(dens), 1)[0] ``

为什么必须除箱宽： 对数箱的宽度正比于 s，若直接用计数拟合，会把 n(s)∝s^{−1.5} 读成 s^{−0.5}。本书第一版就是这么错的（见 R.4 第 5 条）。

B.4　十个短案例

每个案例只给三样：什么在变、有没有临界点、判定。用来练手。

  1. 水沸腾：什么在变——气泡密度；临界点——100°C；判定：严格相变（一阶）。
  2. 磁体退磁：什么在变——净磁化；临界点——居里温度；判定：严格相变（二阶）。
  3. 图的连通：什么在变——最大连通块占比；临界点——β₁、β₂；判定：严格相变。
  4. 学习高原：什么在变——巩固速度；临界点——容量饱和；判定：可能是相变。
  5. 公司垮掉：什么在变——可持续性；临界点——不明确；判定：渐进退化（不是相变）。
  6. 疫情拐点：什么在变——R_t；临界点——R_t=1；判定：诊断级。
  7. 金融危机：什么在变——杠杆/利差；临界点——不明确；判定：诊断级（慢化明显）。
  8. 技术引爆点：什么在变——采用率；临界点——事后叙事；判定：隐喻级。
  9. 社会极化：什么在变——极化指数；临界点——不明确；判定：隐喻级（不可通约）。
  10. 历史范式转移：什么在变——学派分化；临界点——无法定位；判定：隐喻级。

练习： 挑一个你熟悉的系统，填这三样。填不出来，就说明它还不是“相变诊断”，只是“变化描述”。
