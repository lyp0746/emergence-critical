第3章　五步流程与反例：把三个标记用起来

反例。同一个流程用在两个几乎相同的系统上，一个给出“已跨门槛”，另一个给出“没有”。复盘发现差别只在指标口径：换一个代理，结论翻转。这说明流程能保证“不漏步骤”，不能保证“选对代理”。选代理仍是判断，不是流程。

本章主提问：有了三个标记，怎么在一个真实系统上把它们用起来？

一张菜谱：备料、热锅、下料、调味、起锅。少一步，菜也能吃，只是不像那道菜。流程不是保证成功，是让你知道漏了哪一步。

3.1　一个五步诊断流程

`` 第 1 步：找序参量 问：什么宏观量在事件前后从≈0 变成明显非 0（或反之）？ 第 2 步：定临界点 问：它在哪个参数值附近跃变？是一阶（跳）还是二阶（连续增长）？ 第 3 步：看预警 问：跃变之前，系统有没有“变慢/变抖/自相关上升”？ 第 4 步：算有效信息 问：宏观描述是否比微观描述更能预测目标？峰值在哪个尺度？ 第 5 步：标等级 三条都中 → 强诊断（A/B）；中两条 → 中等（B）；只中一条 → 弱（C，只是“像”）。 ``

图 3.1　五步诊断流程。五步流程从左到右，每一步的输入与输出写在框内；跳过任何一步，诊断就退化成表态。

3.2　三个反例：什么“不是”质变

反例一：一家公司的业绩下滑。

  • 序参量：利润从正变负——这是“变号”，不是“从 0 到非 0”，不构成相变序参量；
  • 临界点：没有明确阈值，下滑是连续的；
  • 临界慢化：没有“恢复变慢”的证据，只是持续恶化。

结论：渐进退化，不是质变。

反例二：一个人换了一份工作。

  • 序参量：没有宏观量从 0 变非 0；
  • 临界点：没有阈值；
  • 临界慢化：没有。

结论：这是“事件”，不是“相变”。 事件可以很重要，但不等于质变。

反例三：一个社会的人口缓慢老龄化。

  • 序参量：老年人口比例连续上升，没有“跃变”；
  • 临界点：没有明确定位（除非你人为设定一个“老龄化社会”的门槛）；
  • 临界慢化：恢复时间没有明显上升。

结论：这是“趋势”，不是“相变”——除非某一天它跨过了一个制度性阈值（如养老金支付能力），那才可能是。

这三个反例的共同点： 它们都是“重要的变化”，但都不满足相变的最小定义。“重要”不等于“相变”。 把一切重要变化都叫“质变”，就是用大词掩盖普通事实。

3.3　十二步：五步流程的展开

五步是骨架，落到一个具体系统上会分成十二个动作。它们不是十二个新步骤，而是同一张流程在「对象—序参量—临界—预警—有效信息—等级」六处的展开；每一步都给出「做对了的样子」，因为流程最容易失败的地方不是不会做，是不知道做到什么程度算做完。

表 3.1　十二步：五步流程的展开。前五步是骨架，后七步是把骨架落到可复核的动作上；「做对了的样子」一列是验收线，不是建议。
步该问的常见错误／陷阱做对了的样子
前置·确定对象与尺度你要诊断的“系统”是什么？它的边界在哪？你用什么尺度看它？对象不清、尺度不明，后面的所有判断都会漂移。对象与尺度写在最前面，后面的判断才有落点。
1·写下“什么在变”什么宏观量，在事件前后从“几乎没有”变成“明显存在”（或反之）？把“变号”当成“跃变”（利润从正变负，不是从 0 到非 0）；把“某个指标上升”当成“某个量从无到有”。你能用一句话说出“什么在变”，而且这句话里有一个可测量的量。
2·写下“它在哪个参数上变”这个量，随着哪个“外部参数”变化？温度？耦合？容量占用比？时间？把“时间”当成参数——时间本身不是参数，时间背后的“某个累积量”才是。你能说出“当 X 从 a 增到 b，这个量会跃变”。
3·判断一阶还是二阶这个量是“跳过去”，还是“连续增长”？把“看起来很快”当成“跳变”——真正的跳变，是“在临界点两侧，取值有质的差别”。你能画出“这个量随参数变化”的曲线，并指出它在哪里“断”或“拐”。
4·找“变之前是否变慢”在临界点之前，系统对扰动的恢复时间，是不是变长了？把“外部冲击太大”当成“临界慢化”——慢化是“系统自己变慢”，不是“外力太大”。你能给出一个“恢复时间”的代理指标（自相关、涨落、恢复时间），并看到它在临界前上升。
5·找“宏观是否更好用”有没有一个“更高层的说法”，比细节更能预测接下来？把“更简洁”当成“更有效”——有效信息衡量的是“预测力”，不是“描述长度”。你能比较两种描述对同一目标的预测力，并指出哪个更高。
6·数一数中了几个三个标记（序参量跃变、临界慢化、有效信息峰值）中了几个？把“我觉得像”算成一个标记——标记必须是“可观测”的，不是“感觉”。你能明确说“中了两个”或“中了三个”，并给出证据。
7·写下“什么会推翻”如果这个判定是错的，会有什么结果出现？写一个“永远不会出现”的条件——那不是可证伪，是免责声明。你写下的条件，是“别人真的能去检验”的。
8·只中一个，改称“像”如果只中一个，我还能叫它“相变”吗？用一个标记，支撑一个“严格”的结论。你改口说“它像相变”，而不是“它是相变”。
9·一个都不中，改称“退化/波动”如果一个都不中，它是什么？硬把它叫“质变”，因为“它很重要”。你说“这是退化/波动”，并说明“重要不等于质变”。
10·标注等级与可反驳条件这个判定有多硬？它在什么情况下错？只标“等级”，不写“条件”——等级是“自评”，条件是“给别人用的”。你给出“证据等级 + 可反驳条件”，让别人能接着做。
收尾·公开、复核、更新别人能不能重做？能不能反驳？只写“结论”，不写“过程”。别人能重做、能反驳，这一步才算走完。

3.4　一句话带走

从数据到判定，最难的不是“算”，而是“在每一步都拒绝自欺”。

【人的尺度】一位政策研究员按五步流程做完一个案例，结论是“还不能判断”。领导问：“那你写了三周干什么？”他说：“我用三周证明了现在不能判断，这也算结论。”流程最不受欢迎的价值，就是它敢给出“不判断”。

本章小结
  • 五步流程：定序参量→找对称破缺→测慢化→试反例→标等级。
  • 反例步骤最容易被跳过，也最能救命。
  • 流程的价值在于它会在你最自信的地方逼你停下。
若这条判据错了，会看到什么：若跳过反例步骤的诊断准确率不低于走完五步的，流程就只是仪式。
