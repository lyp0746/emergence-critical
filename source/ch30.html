第三十章　边界（二）：约束、可行域与 KKT

第二十八章讲"边界决定性质"的直觉。这一章把它形式化：约束优化、可行域、KKT 条件——这是"边际"与"边界"的数学骨架。

30.1　约束优化

`` max f(x) s.t. g_i(x) ≤ 0, h_j(x) = 0 ``

可行域 𝔽 = {x : g_i(x)≤0, h_j(x)=0}。最优解可能在"内部"，也可能在"边界"。

30.2　拉格朗日乘子

对等式约束 h(x)=0，构造：

`` L = f(x) − λ h(x) ``

一阶条件：∇f = λ ∇h。几何意义：在最优解处，目标函数的梯度，与约束曲面的法向平行。

λ 的经济意义：影子价格。 约束放松一单位，目标能增加 λ。

30.3　KKT 条件

对不等式约束，最优解满足：

`` ∇f = Σ μ_i ∇g_i + Σ λ_j ∇h_j μ_i ≥ 0, μ_i g_i = 0 g_i ≤ 0, h_j = 0 ``

关键是"互补松弛" μ_i g_i = 0：

  • 若约束不起作用（g_i<0），则 μ_i=0；
  • 若约束起作用（g_i=0，在边界上），则 μ_i≥0。

这就是"边界解"与"内点解"的数学区分： 内点解里，约束的"价格"为零；边界解里，约束有正价格。

30.4　与"边际"的关系

在经济学里：

  • ∇f 是"边际收益"；
  • ∇g 是"边际成本"；
  • λ、μ 是"边际约束的价格"。

所以，"边际分析"就是"在边界上做导数"。 不是在"总量"上做文章，而是在"再走一步"上做文章。

30.5　与 C-A-T 三角的关系

本书的 C-A-T 三角，本质上是一个可行域：

  • 三项预算 Σ ≤ K；
  • 三角的边界，就是"可行域的边界"；
  • "让出哪一个顶点"，就是"在边界的哪一段"。

"诊断"的动作，就是"找边界"：不是问"系统内部怎么运作"，而是问"它撞到了哪条边界"。

30.6　分岔：稳定性的边界

除了"约束边界"，还有"稳定性边界"。

设系统 ẋ = F(x, μ)。平衡点 x*(μ) 的稳定性，由 Jacobian J = ∂F/∂x 的特征值决定：

  • 所有特征值实部为负 → 稳定；
  • 有特征值实部为正 → 不稳定；
  • 特征值实部过零 → 分岔。

分岔点，就是"稳定性边界"。 越过它，系统的"质"就变了。

30.7　三种边界，一个结构

边界类型数学例子
约束边界KKT、可行域预算、产能、三角
稳定性边界特征值过零、分岔失稳、振荡、临界慢化
相边界自由能极小切换固/液/气、序参量跃变

三者都是"边界决定性质"的不同写法：

  • 约束边界决定"能做什么"；
  • 稳定性边界决定"稳不稳"；
  • 相边界决定"是什么相"。

30.8　一句话带走

"边际"是在边界上做导数，"分岔"是稳定性过零，"相变"是自由能极小切换——三者都是"边界决定性质"。
