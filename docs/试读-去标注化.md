# 试读章（去标注化版）：三个信号

> 本文件是一次文体实验：把第 3 章改写成叙述体，**去掉 A/B/C 标注、去掉“本书不是”式声明、去掉警告框**。它不进入正文，也不改变原书结构。

---

夜班护士交接时说了三句话：三号床昨晚发烧，七号床家属情绪不对，十一号床明天复查。

前两句是常规。第三句她说得很轻：“十一号床，这几天拉不回来了。”

拉不回来，是一个很土的说法。它的意思是：同样一针药，前天半小时能把血压顶上去，昨天要一小时，今天顶上去两个小时又掉下来。**不是数值更差，是系统越来越费劲。**

第二天凌晨，十一号床进了抢救室。

---

## 一、变天之前，会先变慢

我们习惯把“变天”想成一个瞬间：水到 100 度就开，公司到某一天就垮，孩子到某一次考试就开窍。

但在那一下之前，系统会先给你一个信号：**它越来越难恢复。**

- 一个人：睡一觉就能缓过来 → 睡两觉还累 → 周末补不回来。
- 一条街：关一家店，很快有人接手 → 空半年 → 整排卷帘门。
- 一台设备：小故障半小时修好 → 修一天 → 修完三天又坏。

这个信号不告诉你“哪一天”，它只告诉你“余量在变少”。**它是唯一一个在事前就能看见的东西。**

---

## 二、还有两个信号，合起来才够

只看“变慢”会误判。有些系统变慢，只是因为它老了、懒了，并没有要变天。

所以还要看另外两件事。

**第一件：有没有一个量，从“几乎没有”变成“明显有”。**

水在 99 度还是水，101 度就是蒸汽——不是“更热”，是“多了一个东西”。一家店每天少十个客人，那叫变差；整条街的业态全换了，那叫另一个东西。

**第二件：有没有一个更粗的说法，比细节更能预测接下来。**

十一号床的细节是：血压、心率、尿量、用药。但那一夜真正有用的判断，是护士那句“这个人最近不太对”。**宏观的说法赢了，因为系统已经变成了另一个东西——一个“随时会崩”的东西。**

三个信号：有量从无到有；变之前越来越难恢复；宏观比细节更好用。

**三个里中两个，可以叫质变。只中一个，叫“像”。一个都不中，那就只是波动。**

---

## 三、为什么这三个信号可信

因为它们不是想出来的，是在一个答案已知的系统上校准过的。

二维格点上的磁铁模型，物理学家早就知道它的临界温度是 2.26919。我们用计算机把它跑了一遍：磁化强度在那附近掉下去，磁化率的峰随尺寸变大而变高，位置向真值靠拢。我们测到 2.2645、峰高指数 1.752——和理论对得上。

对不上的地方也写下来了：另一个指数测出来偏大 25%，还有一个根本测不出来。**这就是校准的意思：不是证明我们对，是知道我们错在哪。**

拿这三个信号去量真实系统，会得到三种结果：严格的、像的、只是比喻的。**分清楚这三种，比多一个术语重要。**

---

## 四、一个反例

人口老龄化常被说成“结构性转变”。它没有临界点：没有哪一年突然变了，每一年都只差一点点，三十年后回头，已经是另一个社会。

三个信号里，它只中一个（宏观更好用），另外两个不中。那它是不是质变？

是。**只不过它是“无临界的质变”。** 这说明三中二是一个够用的筛子，不是宇宙定律。**筛子会漏东西，漏掉的东西要单独说。**

---

## 五、三问

所以这本书最后只留三个问题，不需要任何公式：

1. 有没有一个东西，从“几乎没有”变成“明显有”？
2. 在它变之前，是不是越来越难恢复？
3. 有没有一个更粗的说法，比细节更能预测接下来？

三个问题问完，你未必能预言什么。但你能分清：**这件事是“更严重了”，还是“换了一个东西”。**

分清这一点，很多决定会变得不一样——包括那个夜班护士要不要在交班本上多写一句“这个人最近不太对”。
