# 第五章　《区分的语法》：严格相变的应用

森林起火，先是一簇火苗，很久以后才连成一条火线。<b>局部的、细碎的变化，总是先于整体的、平滑的变化。</b>


## 5.1　《区分的语法》：严格相变的应用

**原著的核心主张。** 用一套语言（区分 + 对称双线性形式）描述不同领域的结构；在一个样本（图的拉普拉斯二次型）上给出完整的两阶段相变定理。**如果这个主张为真，意味着：看起来完全不同的数学对象，其实是同一结构在不同坐标系里的表现。**〔原著〕

**定理本身（为什么它是"硬"的）。** 区分强度按 `Ḋ = (−αI + βL)D` 演化，临界耦合为：

```
β₁ = α/λₙ   （最高频、最局部的模式先解锁）
β₂ = α/λ₂   （Fiedler、最全局的模式后解锁）
```

具体数字（α=1）：Petersen 图 `(0.200, 0.500)`；环 `C₁₀ (0.250, 2.618)`。**证明只用实对称矩阵的谱定理与线性 ODE，是标准数学。**〔原著，定理〕

**三个标记逐一。**
- **序参量**：`η = |C_max|/N`（最大连通块占比）。临界点 `β₁`、`β₂`。**有，可计算。**
- **临界慢化**：临界点附近多个特征值聚集，系统对小扰动更敏感。**有（本书推断）。**
- **有效信息**：全局连通性对所有边行为的预测力，高于任何单条边。**有（本书推断）。**

**如果换一套诊断框架。** 把它看成"纯代数问题"（不算相变），结论**不变**：因为它确实有阈值、有跃变、有模式解锁。**这是五本里唯一"换框架也不影响判定"的。**

**证据链。**
```
原著主张（定理，A/甲）
  → 本书诠释（忠实转述，A/甲）
  → 本书判定（严格相变，A/甲）
```

**信号强度。** **强信号（>90%）**——不是"概率 90%"，而是"证据强度在这一档"。

**什么会改变判定。** 如果发现某类图**没有**明确的阈值（例如边权连续变化时模式始终平滑增长），那"严格相变"就要降级为"可能是"。

**还缺。** 临界指数 α；一阶/二阶的明确归类（有限图上更接近二阶〔本书推断〕）。

### 5.1.1　定理的证明逻辑（为什么它“硬”）

这条定理之所以硬，是因为它只用了两件标准工具：

1. **实对称矩阵的谱定理**：`L` 是实对称半正定的，所以有一组正交特征向量与实特征值 `0=λ₁≤…≤λₙ`；
2. **线性 ODE 的解**：`Ḋ = (−αI + βL)D` 的解，是各特征模式 `e^{(-α+βλ_k)t}` 的叠加。

于是“哪个模式先增长”，只取决于 `−α+βλ_k` 何时由负变正，即 `β = α/λ_k`。**两个临界值，就是最大和次小特征值对应的两个 β。**〔原著，定理〕

### 5.1.2　一个可以手算的例子

以环 `C₁₀` 为例（α=1）：`λ₂ ≈ 0.382`，`λₙ = 4`。于是

```
β₁ = 1/4 = 0.25
β₂ = 1/0.382 ≈ 2.618
```

**中间隔了十倍。** 意思是：局部模式早在 β=0.25 就开始长，而全局模式要等到 β≈2.618。**这不是“差不多同时”，而是“差了整整一个数量级”。**

### 5.1.3　边界条件

- 这套结论对**有限、连通、无向**图成立；
- 对**有向图**，顺序可以反转（原著给了 6 顶点反例）；
- 对**连续流形**，需要另作处理（1/3 缺口由此而来）。

**所以，“严格相变”是有边界的：它只在“有限无向图”这个范围内严格。**

### 5.1.4　谱分析：为什么是“两阶段”

拉普拉斯谱 `0=λ₁<λ₂≤…≤λₙ` 里，**最大的 λₙ 对应“最高频、最局部”的模式，次小的 λ₂ 对应“最全局”的模式**。于是：

- β 刚超过 `α/λₙ`，只有最高频模式能增长——**局部先醒**；
- β 超过 `α/λ₂`，全局模式才增长——**全局后醒**。

**“两阶段”不是作者硬造的，而是谱的两端决定的。** 这就是它“硬”的原因：你换不掉这个顺序，除非图不对称。

### 5.1.5　Petersen 图：一个可以画出来的例子

Petersen 图的临界值是 `(0.200, 0.500)`。把它画出来：外五边形、内五角星、五条辐条。**当 β 从 0 增大，先是五条辐条上的局部差异开始放大，然后整个图的“两半”才分开。** 这就是“局部先于全局”的可视化。

### 5.1.6　这个应用告诉我们什么

它告诉我们：**“严格相变”是可能的，但它需要三个条件同时满足**——有限、无向、谱可算。**一旦这三个条件缺一个，结论就要降级。** 这也是后面四章“降级”的起点。

### 5.1.7　原著论证的完整链条

这本书的论证不是从“相变”开始的，而是从“区分”开始的：

1. **区分动作**：把对象分辨开的最小操作（一把尺子、一个探针、一个开集）；
2. **不可区分关系**：在给定精度下，分不开的东西被视为等价；
3. **对称双线性形式**：把“两个对象的关联”写成最简代数表达 `B(x,y)`；
4. **谱**：`B` 的特征值决定长期行为；
5. **样本**：在图的拉普拉斯二次型上，谱给出两阶段相变。

**所以，相变不是这本书的“结论”，而是它“语言”的一个样本。** 这一点很重要：它说明“相变”可以从“区分 + 形式”里长出来，而不是硬贴上去。〔原著〕

### 5.1.8　数值复现：两张图，两组数字

| 图 | `λ₂` | `λₙ` | `β₁=α/λₙ` | `β₂=α/λ₂` | 中间相宽度 |
|---|---|---|---|---|---|
| Petersen | 2.000 | 5.000 | 0.200 | 0.500 | 0.300 |
| 环 C₁₀ | 0.382 | 4.000 | 0.250 | 2.618 | 2.368 |

**环的中间相宽了将近八倍。** 直观地说：在环上，“局部先醒”之后，要等很久“全局才醒”；而在 Petersen 图上，两者挨得很近。**这就是“谱决定相变结构”的具体含义。**〔原著，可复算〕

### 5.1.9　反例：有向图可以反转

原著给了一个 6 顶点有向图的反例：首个增长模式的 `Re(λ)=2.0`、总变差 `TV=0.25`（全局），在 `β=0.5` 时增长；较晚增长的模式 `Re(λ)=1.0`、`TV=0.7071`（局部），要等到 `β=1.0`。**全局先于局部——顺序反转了。**

**为什么？** 因为耦合矩阵不再对称，特征值可以是复数，非正规性让“增长顺序”不再由谱的两端决定。**这是“严格相变”的边界：对称性一破，结论就变。**〔原著，反例 A／甲〕

### 5.1.10　与另外四本的对照

- 比《遗忘》：它有“定理”，遗忘只有“框架”；
- 比《错位》：它有“精确临界值”，错位只有“τ≈1”的量级；
- 比《选择》：它有“跃变”，选择只有“前沿”；
- 比《诠释》：它有“可复算”，诠释只有“可解释”。

**所以它是“上限”：如果连它都不算严格相变，那这套框架就没有“严格”可言了。**

### 5.1.11　可反驳清单

1. 若某类**对称加权**图出现“全局先于局部”，定理 B1 被推翻；
2. 若 `κ_info = Var(λ)/2` 在某个图上不成立，恒等式被推翻；
3. 若“1/3 缺口”能被代数消去，“传递性被让出”被削弱；
4. 若临界指数 α 在同一图类中不唯一，“普适类”被削弱。

### 5.1.12　一张可以复算的谱表

| 图 | `λ₂` | `λₙ` | `β₁` | `β₂` | 中间相 |
|---|---|---|---|---|---|
| Petersen | 2.000 | 5.000 | 0.200 | 0.500 | 0.300 |
| 环 C₁₀ | 0.382 | 4.000 | 0.250 | 2.618 | 2.368 |
| 完全图 Kₙ | n | n | 1/n | 1/n | 0（无中间相） |

**完全图没有中间相**——这是“全连通”的极端：局部与全局同时解锁。**这张表说明：相变结构由谱决定，不是由“图的形状”决定。**

### 5.1.13　如果把它当成纯代数

如果有人说“这只是线性代数，不是相变”，本书的回应是：**对，它是线性代数；但“相变”本来就可以是线性代数的。** 关键在于：它有没有阈值、有没有跃变、有没有模式解锁。**这三条它都有。**

**所以，判定“是不是相变”，不取决于“用不用物理词”，而取决于“结构对不对”。**

### 5.1.15　原著论证的完整回顾（给想深读的人）

1. **起点**：区分动作——把对象分辨开的最小操作；
2. **关系**：不可区分关系——在给定精度下，分不开的被视为等价；
3. **代数化**：把“关联”写成对称双线性形式 `B(x,y)`；
4. **谱**：`B` 的特征值决定长期行为；
5. **样本**：图的拉普拉斯二次型 `xᵀLx=Σ(xᵤ−xᵥ)²`；
6. **动力学**：`Ḋ=(−αI+βL)D`；
7. **定理**：`β₁=α/λₙ`、`β₂=α/λ₂`，局部先于全局；
8. **归并**：曲率、演化两个原语被归并进“形式”；
9. **定位**：这是一套“语言”，不是“新理论”。

**这九步，就是这本书的骨架。** 相变只是第 7 步的“样本”，但它是最硬的一步。

### 5.1.16　原著的核心概念（长文）

这本书真正想说的，不是“相变”，而是“区分”。

**什么叫“区分”？** 它不是“把一个东西分成两半”这么简单。它是一个**动作**：你拿一把尺子、一个探针、一个开集，去问“这两个东西是不是一样”。这个动作一旦发生，世界就被切成了“可区分的”和“不可区分的”。

**为什么要用“二次型”？** 因为“两个东西有多像”这件事，最自然的代数表达，就是一个对称双线性形式 `B(x,y)`。它满足三条：对称、线性、正定（或不定的）。这三条，恰好就是“相似性”该有的性质。协方差、Hessian、图拉普拉斯、内积、黎曼度量，都是它的实例——不是“五个工具”，而是“同一个工具的五种写法”。

**为什么“谱”重要？** 因为谱决定“长期行为”。短期的细节会互相抵消，长期的趋势只由特征值决定。**一个系统的“性格”，藏在它的谱里。** 你想要知道它会不会裂、会不会同步、会不会振荡，看谱就够了。

**为什么“两阶段”？** 因为谱有两端：最大的特征值对应“最局部”的模式，次小的对应“最全局”的模式。当耦合从 0 增大，局部模式先解锁，全局模式后解锁。**“局部先于全局”不是哲学，是谱的排序。**

**这本书的“降级”是什么？** 它没有说“我统一了数学”。它说：“我有一套语言，可以描述这些结构；这套语言是否值得用，要看它有没有被采纳。”**这是一种“语言规范”的姿态，不是“新理论”的姿态。**

**这跟“相变”有什么关系？** 关系是：**“区分”是相变的“前一步”。** 你必须先能区分“两个相”，才谈得上“相变”。**所以，这本书是“相变”的语法书，不是“相变”的定理书。**

### 5.1.17　一个详细案例：如果社会网络像 Petersen 图

假设一个 10 人社群，关系结构恰好是 Petersen 图（外五边形、内五角星、五条辐条）。**它的两个临界值是 (0.200, 0.500)。**

- 当“关系强度”β < 0.2：任何小分歧都会衰减，社群回到一致；
- 当 0.2 < β < 0.5：**局部小圈子开始固化**，但整体还没分裂；
- 当 β > 0.5：**整体分裂成两半**。

**这给出一个可操作的预测：** 如果你能测出这个社群的“关系强度”和它的谱，你就能预测“它先局部固化，还是先整体分裂”。**这是本书里少数“可以真的算”的社会预测。**

## 5.2　.2　定理的“最小证明”
设图 `G` 有拉普拉斯 `L`，谱 `0=λ₁<λ₂≤…≤λₙ`。区分强度 `D` 满足：

```
Ḋ = (−αI + βL)D
```

把 `D` 按 `L` 的特征向量展开：`D(t)=Σ c_k e^{(−α+βλ_k)t} v_k`。

- 当 `βλ_k < α`，第 k 个模式衰减；
- 当 `βλ_k > α`，它增长。

**所以，“哪个模式先增长”只取决于 `λ_k` 的大小。** 最大的 `λₙ` 最先满足，次小的 `λ₂` 最后满足。**这就是两阶段的全部证明。**

## 5.3　.3　数值：为什么环的中间相那么宽
环 `C₁₀`：`λ₂≈0.382`、`λₙ=4`。于是 `β₁≈0.25`、`β₂≈2.618`，中间相宽 `2.368`。

Petersen 图：`λ₂=2`、`λₙ=5`。于是 `β₁=0.2`、`β₂=0.5`，中间相宽 `0.3`。

**环的中间相宽了约八倍。** 直观地说：环上“局部先醒”之后，要等很久“全局才醒”；Petersen 图上两者挨得很近。

## 5.4　.4　边界：三条例外
1. **有向图**：顺序可反转（原著给了 6 顶点反例）；
2. **连续流形**：需要另作处理（1/3 缺口）；
3. **非对称加权**：谱变成复数，结论要重写。

**所以，“严格相变”只在“有限、无向、对称”的范围内严格。**

## 5.5　.5　它和“本书框架”的关系
这本书是“本书框架”的**上限**：它证明“相变可以被写成定理”。

但它也是“本书框架”的**边界**：它证明“定理需要三个条件”。**一旦条件缺一个，定理就退化成诊断。**

## 5.6　.6　什么会推翻它
- 若某类对称加权图出现“全局先于局部”，定理 B1 被推翻；
- 若 `κ_info=Var(λ)/2` 在某个图上不成立，恒等式被推翻；
- 若“1/3 缺口”能被代数消去，“传递性被让出”被削弱。

**这三条，就是它的“死穴”。**

### 5.1.23　一个社会网络的完整诊断

假设一个 10 人社群，关系结构是 Petersen 图。我们按十步走一遍。

**第一步：对象与尺度。** 这个社群，看“月”尺度。

**第二步：质变描述。** 从“一个整体”到“两个小圈子”。

**第三步：把质变成量。** 序参量：最大连通块占比 `η`。

**第四步：临界点。** `β₁=0.2`（局部先固化）、`β₂=0.5`（整体分裂）。

**第五步：一阶/二阶。** 有限图上更接近二阶。

**第六步：慢化。** 临界点前，社群对“小分歧”的恢复时间变长——一次争吵后，和好所需的时间从几天变成几周。

**第七步：有效信息。** “这个社群正在分裂”比“谁和谁吵了架”更能预测接下来的结构。

**第八步：数标记。** 序参量 + 慢化 + 有效信息 = 三个。

**第九步：可反驳条件。** 若 `β` 超过 0.5 后，社群又通过“跨圈关系”重新连通，则“分裂”判定被削弱。

**第十步：等级。** A／甲（可计算、可复现）。

**这个诊断的价值：** 它把“社群会不会分裂”从“感觉”变成了“可计算的阈值”。**这是全书里少数“可以真的算”的社会诊断。**

## 5.7　严格相变能给我们什么：三条，不多不少

《区分的语法》里的两阶段相变，是这套框架里唯一“完全兑现”的部分：有定理、有临界值、有可复算的数值。正因为它硬，才更要说清它到底给了什么。

**给的第一样：一个“局部先于全局”的判据。** 定理给出两个临界耦合 β₁=α/λₙ 与 β₂=α/λ₂：β 超过 β₁ 时，最高频（最局部）的模式先失稳；超过 β₂ 时，Fiedler 模式（最全局）才失稳。**这不是比喻，而是可以算出来、并且顺序不会反转的结论**（在正对称边权下）。它给了一个可操作的判断：**当你看到“局部的小变化”先出现时，不要急着说“全局还没动”，因为全局模式可能确实还没有长出来。**

**给的第二样：一个“顺序可以被打破”的条件。** 定理 B2 给出反例：当关系变成有向（不对称）时，全局模式可以先于局部模式增长。**这条反例比定理更有价值**，因为它把“局部先于全局”从一个普遍规律降级为“对称性下的规律”——而对称性是可以被检查的。

**给的第三样：一个可复算的数值。** 环 C₁₀ 的两个临界值是（0.25, 2.618），相差十倍。**这十倍的间隔是可以被任何人用二十行代码验证的。** 它说明“中间那段只有局部在动”的窗口有多宽。

**它没有给的三样，同样重要：**

- **没有给“社会系统里的 λ₂ 是多少”。** 图上相变要求一个给定的图与给定的拉普拉斯谱；社会系统的“关系图”既不可完整观测，也不稳定。
- **没有给“相变一定发生”。** 定理说的是“当 β 越过阈值时哪个模式先增长”，不是“β 一定会越过阈值”。
- **没有给“临界指数”。** 这套构造是线性的，指数结构（β、γ、ν）在这里无从谈起；**把它当成“普适类”的证据，是越界。**

<div class="box box-more2"><p><b>【再想一层】</b>一个严格的模型，最大的用处往往不是“解释世界”，而是<b>给其他领域的类比划一条不能越过的线</b>：你可以借它的“局部先动”，但不能借它的“指数”。借错了，就是 22.27 那条误用。</p></div>

> 【人的尺度】一位数学系学生看到两阶段相变的临界值，说：“这不就是‘局部先动’吗？生活里也是这样：小区里先有几户开始垃圾分类，很久以后整个城市才动。”<b>严格的结果之所以动人，是因为它在某个具体的傍晚被人认了出来。</b>
