# 第二十七章　推导与解析（三）：图拉普拉斯、渗流与复杂网络

> 这一章给“图上的相变”一套完整推导：从拉普拉斯谱，到两阶段相变，再到渗流与网络。

## 27.1　图拉普拉斯

设图 `G=(V,E)`，度矩阵 `D`，邻接矩阵 `A`。拉普拉斯：

```
L = D − A
```

二次型：

```
xᵀLx = Σ_{(u,v)∈E} (x_u − x_v)²
```

**它衡量“x 在边上有多不平”。** `x` 越平滑，`xᵀLx` 越小。

## 27.2　谱与连通性

`L` 是实对称半正定，谱 `0=λ₁ ≤ λ₂ ≤ … ≤ λₙ`。

- `λ₁=0` 对应常数向量（全图一致）；
- `λ₂`（Fiedler 值）衡量“图有多容易裂成两半”：`λ₂` 越小，越容易裂。

**这就是“谱决定连通性”的数学版本。**

## 27.3　线性动力学：临界耦合

设区分强度 `D` 满足：

```
Ḋ = (−αI + βL) D
```

按特征向量展开，第 k 个模式的增长率是 `−α + βλ_k`。

**临界条件：** `−α + βλ_k = 0`，即 `β = α/λ_k`。

- 最大的 `λₙ` 对应“最高频、最局部”的模式，临界 `β₁ = α/λₙ`；
- 次小的 `λ₂` 对应“最全局”的模式，临界 `β₂ = α/λ₂`。

**因为 `λ₂ ≤ λₙ`，所以 `β₁ ≤ β₂`——局部先解锁，全局后解锁。** 这就是“两阶段相变”的全部推导。

## 27.4　数值例子

| 图 | `λ₂` | `λₙ` | `β₁` | `β₂` |
|---|---|---|---|---|
| Petersen | 2 | 5 | 0.2 | 0.5 |
| 环 C₁₀ | 0.382 | 4 | 0.25 | 2.618 |
| 完全图 Kₙ | n | n | 1/n | 1/n |

**完全图无中间相**，因为 `λ₂=λₙ`，两个临界点重合。

## 27.5　渗流：另一种“图上的相变”

**模型。** 每条边以概率 `p` 保留，问“是否存在一个无限大连通块”。

**临界概率。** 二维方格：`p_c ≈ 0.593`（座渗流）、`p_c = 0.5`（边渗流）。

**临界行为。** 在 `p_c` 附近：

```
P_∞ ∝ (p − p_c)^β,   β = 5/36 ≈ 0.139（2D）
```

**集团分布：** `n_s ∝ s^{−τ} exp(−s/s*)`，2D 的 `τ = 187/91 ≈ 2.055`。

**分形维数：** 在 `p_c`，最大集团 `∝ N^{d_f/d}`，2D 的 `d_f = 91/48 ≈ 1.896`。

**渗流是“最干净的相变样本”之一：** 它有精确的临界概率、临界指数、分形维数。

## 27.6　复杂网络上的渗流

**随机图。** `G(N,p)`，平均度 `⟨k⟩`。临界点 `p_c = 1/⟨k⟩`。

**一般网络。** 用“分支因子” `κ = ⟨k²⟩/⟨k⟩`，临界点 `p_c = 1/(κ−1)`。

**无标度网络。** 若度分布 `P(k) ∝ k^{−γ}`：

- `γ > 3`：`⟨k²⟩` 有限，`p_c > 0`；
- `2 < γ ≤ 3`：`⟨k²⟩` 发散，`p_c → 0`。

**这意味着：** 无标度网络对“随机故障”极其鲁棒（`p_c→0`），但对“针对性攻击”极其脆弱（攻击枢纽节点）。

**这就是“鲁棒却脆弱”的数学版本。**

## 27.7　这对本书的意义

**这是全书唯一“可以完全算出来”的部分。** 它说明：**“相变”不是比喻，而是可以从谱、从概率、从网络结构推出来的。**

**但它也说明：** 一旦离开“图”这个对象，推导就变得困难。**这正是“形式化地平线”的数学根源。**

## 27.8　Fiedler 值的界

`λ₂` 与“图的连通性”有严格的界：

```
λ₂ ≤ (n/(n−1)) · min_{v} deg(v)
```

**它说明：** 度数越小的节点，越限制“全局连通”。**这就是“瓶颈”的谱版本。**

**另一个界：** `λ₂ ≤ 2 · edge_connectivity / n`。**边连通性越小，`λ₂` 越小，越容易裂。**

## 27.9　谱与随机游走

在图上做随机游走，转移矩阵 `P = D^{−1}A`。**它的特征值与拉普拉斯谱直接相关：**

```
μ_k = 1 − λ_k / d   （对 d-正则图）
```

**混合时间**（走到稳态的时间）由 `1/(1−μ₂) = d/λ₂` 决定。**`λ₂` 越小，混合越慢。**

**这给“慢化”一个图论版本：** 图越“接近分裂”，随机游走越慢——**“临界慢化”在图上的对应。**

## 27.10　网络渗流的严格条件

对配置模型（给定度分布），渗流阈值：

```
p_c = 1 / (κ − 1),   κ = ⟨k²⟩ / ⟨k⟩
```

**推导要点：** 从“一个节点出发，沿边能到达的节点数”的分支过程，临界条件是“分支因子 = 1”。

- 若 `κ>2`：`p_c>0`，有“有限阈值”；
- 若 `κ≤2`：`p_c=0`，任意小的 `p` 都能连通。

**无标度网络 `P(k)∝k^{−γ}`：** `γ≤3` 时 `⟨k²⟩` 发散，`κ→∞`，`p_c→0`。**这就是“鲁棒却脆弱”的严格版本。**

## 27.11　与本书两阶段相变的关系

本书的“两阶段相变”（`β₁=α/λₙ`、`β₂=α/λ₂`）是**“线性动力学”**的结果；渗流是**“随机连通”**的结果。

**两者不同：** 前者是“确定性的模式解锁”，后者是“随机的集团生长”。

**但它们共享一个结构：** **都是“图上的阈值现象”**——跨过某个 `p` 或 `β`，全局性质改变。

**这正是“同约束而不同构”的例子：** 同一张图，两种机制，两种相变。
