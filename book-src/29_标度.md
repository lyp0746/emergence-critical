# 第二十九章　推导与解析（四）：有限尺度标度与临界指数的估计

> 理论给了临界指数，但"怎么从数据里把它估出来"？这一章讲有限尺度标度——这是把"相变"从"概念"变成"可测量"的关键技术。

## 29.1　为什么需要有限尺度标度

在无限系统里，关联长度 `ξ` 在临界点发散。但任何真实系统都是**有限大小** `L`。

**有限大小会"抹平"临界点：** `ξ` 最多长到 `L`，所以临界行为被"圆滑"了。**你直接测，永远测不到"尖锐的奇点"。**

**解决办法：** 用不同 `L` 的数据，做"标度坍缩"。

## 29.2　标度假设

设某个可观测量 `A`（如磁化、序参量）满足：

```
A(L, T) = L^{ω/ν} · f( L^{1/ν} (T − T_c) )
```

其中 `ν` 是关联长度指数，`ω` 是 `A` 的标度维数，`f` 是标度函数。

**这个假设的意思是：** 不同 `L` 的曲线，只要按 `L` 重新标度，就会"坍缩"到同一条 `f` 上。

## 29.3　数据坍缩：三步

**第一步：固定 `T_c` 与 `ν` 的猜测值。**

**第二步：把每个 `L` 的数据，画成 `L^{−ω/ν} A` 对 `L^{1/ν}(T−T_c)`。**

**第三步：调 `T_c`、`ν`、`ω`，直到所有曲线"叠成一条"。**

**叠得越好，参数越可信。** 这就是"用数据估临界指数"的标准做法。

## 29.4　Binder 累积量：更稳的 `T_c` 估计

```
U = 1 − ⟨m⁴⟩ / (3⟨m²⟩²)
```

**为什么用它？** 因为不同 `L` 的 `U` 曲线，**在 `T_c` 处相交**。**交点就是 `T_c`，而且它不依赖 `ω`。**

**这是"最稳"的 `T_c` 估计法之一。**

## 29.5　一个可复算的例子

以二维伊辛为例（`T_c≈2.269`）：

- 取 `L=16, 32, 64, 128`；
- 每个 `L` 跑 Monte Carlo，测 `m`、`χ`、`U`；
- 画 `U` 对 `T`，找交点 → `T_c`；
- 画 `m L^{β/ν}` 对 `L^{1/ν}(T−T_c)`，调 `β/ν`、`ν` 直到坍缩；
- 得到 `β≈0.125`、`ν≈1`。

**这与 Onsager 的精确解一致。** 这就是"数值验证理论"的完整流程。

## 29.6　这对本书的意义

**它说明"临界指数"不是"哲学词"，而是"可以估出来的数"。** 但本书也承认：**这套方法需要"可重复的实验/模拟"与"大样本"。**

**社会/历史系统，两条都不满足。** 所以，本书只能借"标度"的**思想**（不同尺度要一起看），不能借"标度坍缩"的**技术**。

## 29.7　一句话带走

> **临界指数之所以可信，不是因为它"推导得漂亮"，而是因为它"能被数据坍缩估出来"。**
